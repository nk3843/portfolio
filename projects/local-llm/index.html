    LangChain Ollama Conversational Agent

    Privacy-First AI Assistant with Tool-Augmented Reasoning

    View on GitHub 1 Star

    Overview

    A production-grade conversational agent that runs entirely on your local machine. Built with LangChain and Ollama, it combines the power of large language models with practical tools like web search, weather, and date retrieval - all without sending your data to the cloud.

    The Problem

    Cloud-based AI services have limitations:

    • 💰 Expensive: API costs add up quickly with usage
    • 🔒 Privacy risks: Your conversations and data leave your machine
    • 🌐 Internet dependency: Requires constant connectivity
    • 📊 Data concerns: Your prompts may be used for training

    The Solution

    Run powerful LLMs locally with tool integration:

    • ✅ Zero API costs after initial setup
    • ✅ Complete data privacy - everything stays on your machine
    • ✅ Works offline (except for tools requiring internet)
    • ✅ Full control over model selection and parameters

    Key Features

    Tool-Augmented Reasoning

    The agent can invoke external tools when needed:

    Tool Purpose Example Query
    DuckDuckGo Search Web search for current information "What's the latest news about AI?"
    Weather Real-time weather data "What's the weather in San Diego?"
    Date/Time Current date and time "What day of the week is it?"

    The agent intelligently decides when to use tools vs when to answer from its internal knowledge.

    Conversational Memory

    Maintains context across the conversation:

    User: "Tell me about Python"
Agent: [Explains Python programming]

User: "What are the best libraries for data science?"
Agent: [Discusses pandas, NumPy, scikit-learn]

User: "Can you give me code examples for the first one?"
Agent: [Provides pandas examples, remembering context]

    Local Model Selection

    Choose from various Ollama models:

    • llama3: General purpose, great reasoning
    • mistral: Fast and efficient
    • codellama: Optimized for code
    • phi3: Lightweight for resource-constrained systems

    Technical Implementation

    Tech Stack

    • LangChain: Agent framework and orchestration
    • Ollama: Local LLM runtime
    • Streamlit: Interactive UI
    • Python 3.9+: Core language
    • DuckDuckGo API: Web search
    • OpenWeatherMap: Weather data

    Agent Design

    ReAct (Reasoning + Acting) pattern:

    1. Thought: Agent reasons about what to do
    2. Action: Decides to use a tool or answer directly
    3. Observation: Processes tool output
    4. Final Answer: Generates response
    # Example agent reasoning
Thought: User wants weather info, I need to use the weather tool
Action: weather("San Diego")
Observation: Temperature: 72°F, Conditions: Sunny
Final Answer: It's currently 72°F and sunny in San Diego!

    Streamlit UI

    Interactive chat interface with:

    • Message history: Full conversation display
    • Model selector: Switch between Ollama models
    • Parameter controls: Adjust temperature, max tokens
    • Tool usage indicators: See when tools are invoked
    • Export conversations: Save chat history

    Key Learnings

    Challenges Solved

    1. Tool Integration: Seamless connection of external APIs to LangChain
    2. Error Handling: Graceful degradation when tools fail
    3. Memory Management: Balancing context length with conversation history
    4. Model Selection: Choosing appropriate models for different tasks

    Technical Decisions

    • Why Ollama? Easy model management and fast local inference
    • Why LangChain? Built-in agent tools and conversation memory
    • Why Streamlit? Rapid UI development with Python
    • Why ReAct? Transparent reasoning process, easier debugging

    Local Setup

    Prerequisites:

    1. Install Ollama from ollama.ai
    2. Pull a model: ollama pull llama3
    3. Clone the repo and install dependencies

    Run the agent:

    streamlit run app.py

    The UI will open in your browser, and all inference happens locally!

    Performance

    • Inference speed: ~15-30 tokens/second (depends on hardware)
    • Memory usage: ~4-8GB RAM for llama3
    • Startup time: <5 seconds
    • Cost: $0 per query (after initial setup)

    Hardware Recommendations

    • Minimum: 8GB RAM, Apple M1 or modern CPU
    • Recommended: 16GB+ RAM, Apple M2/M3 or GPU
    • Storage: 5-10GB per model
