    ML Algorithms Library

    Comprehensive Machine Learning Implementation Collection

    View on GitHub

    Overview

    A complete machine learning library implemented from scratch with comprehensive documentation, web interface, and ready-to-use implementations of classification, clustering, and dimensionality reduction algorithms.

    Perfect for learning ML fundamentals, rapid prototyping, or understanding what scikit-learn does under the hood.

    Implemented Algorithms

    Classification

    Naive Bayes

    Multiple variants for different data types:

    • Gaussian Naive Bayes: Continuous features
    • Multinomial Naive Bayes: Text classification
    • Bernoulli Naive Bayes: Binary features

    Best for: Text classification, spam detection

    K-Nearest Neighbors (KNN)

    Feature-rich implementation:

    • Custom distance metrics (Euclidean, Manhattan, Minkowski)
    • Weighted voting
    • K-fold cross-validation

    Best for: Pattern recognition, recommendation systems

    Decision Trees

    Information theory-based classifier:

    • Information gain criterion
    • Gini impurity criterion
    • Tree visualization

    Best for: Interpretable models, feature importance

    AdaBoost

    Ensemble learning algorithm:

    • Custom base estimators
    • Weighted voting
    • Error analysis

    Best for: Improving weak classifiers

    Clustering

    K-Means

    Unsupervised clustering:

    • Multiple initialization strategies
    • Elbow method for optimal K
    • Cluster visualization

    Best for: Customer segmentation, image compression

    Dimensionality Reduction

    PCA (Principal Component Analysis)

    Feature engineering and visualization:

    • Variance analysis
    • Componentselection
    • Feature importance ranking

    Best for: Visualization, noise reduction, feature extraction

    Usage Examples

    Command Line

    from algorithms.classification import KNN
from algorithms.clustering import KMeans
from utils.metrics import accuracy_score

# Classification
knn = KNN(k=5, metric='euclidean')
knn.fit(X_train, y_train)
predictions = knn.predict(X_test)
acc = accuracy_score(y_test, predictions)

# Clustering
kmeans = KMeans(n_clusters=3)
kmeans.fit(X)
clusters = kmeans.predict(X)

    Algorithm Deep Dives

    Naive Bayes Mathematics

    Bayes Theorem:

    P(class|features) = P(features|class) × P(class) / P(features)

    Naive assumption: Features are independent

    KNN Decision Process

    graph LR
    A[New Point] --> B[Calculate Distances]
    B --> C[Find K Nearest]
    C --> D{Weighted?}
    D -->|Yes| E[Weight by Distance]
    D -->|No| F[Simple Vote]
    E --> G[Predict Class]
    F --> G

    Decision Tree Splitting

    Information Gain:

    IG(D, A) = Entropy(D) - Σ |Dv|/|D| × Entropy(Dv)

    Choose attribute A that maximizes information gain.
